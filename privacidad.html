Política de privacidad

Aplicación de subida de Cosas con Sal · Actualizada el 1 de noviembre de 2026

A quién se aplica

Esta política describe la aplicación «Cosas con Sal», una herramienta privada que el canal de YouTube Cosas con Sal usa para subir y programar sus propios vídeos mediante la API de datos de YouTube. La usa únicamente el dueño del canal, con su propia cuenta de Google.

Qué datos usa

La aplicación pide a Google permiso para:

  • subir vídeos al canal (youtube.upload);
  • consultar la información y las estadísticas del propio canal (youtube.readonly);
  • gestionar los vídeos del propio canal: miniaturas, subtítulos y fecha de publicación (youtube.force-ssl).

Solo trabaja con el canal de su dueño. No recoge, no guarda y no comparte datos de otros usuarios de YouTube ni de Google.

Dónde se guarda

El permiso que concede Google (el token de acceso) se guarda solo en el ordenador del dueño del canal. No se envía a ningún servidor propio ni a terceros, y no se vende ni se usa para publicidad.

Uso de los datos de Google

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. La aplicación también se rige por las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Cómo retirar el permiso

El permiso se puede retirar en cualquier momento desde la página de seguridad de la cuenta de Google: myaccount.google.com/permissions.

Summary in English

«Cosas con Sal» is a private tool used only by the owner of the Cosas con Sal YouTube channel to upload and schedule videos on that channel through the YouTube Data API. It only accesses the owner's own channel, stores the OAuth token locally on the owner's computer, and does not collect, store or share data from any other user. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: tecnologiaconsal@gmail.com.
